# Guía de Inicio para Desarrolladores 

## 1. Setup del Entorno
* **IDE**: Utilizamos Visual Studio Code para mantener un flujo ligero y ágil.
* **Extensiones Obligatorias**: Debes instalar el "Extension Pack for Java" y "PlantUML" para ver los diagramas.

## 2. Flujo de Trabajo (GitFlow)
* **Rama `develop`**: Siempre saca tus ramas de trabajo desde aquí.
* **Commits**: Usa mensajes descriptivos. No pongas mensajes de "cambios finales" sin especificar los cambios realizados, mejor usa "Añadida validación de temperatura en clase Sensor".

## 3. Estructura del Proyecto
* `/docs`: Toda la documentación técnica y diagramas que necesites consultar.
* `/src`: Aquí está la lógica de las clases principales del sistema.
